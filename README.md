# EzeLabs — Official Website

EzeLabs is a website for showcasing independently developed applications and providing users with product information, support resources, and privacy documentation.

## Overview

This repository contains the EzeLabs website, including information and support pages for Puti, a published iOS application.

## Featured Application

### Puti — Remember Where You Put Things

Puti helps users remember where they stored everyday belongings by saving item names, locations, photos, and notes.

**[View Puti on the App Store](https://apps.apple.com/us/app/puti/id6809547675)**

## Technologies

- HTML
- Git and GitHub
- GitHub Pages for website deployment

- `index.html` — Main website page
